# amplitargets
Target repository for panels designed and compatible with [amplitools](https://github.com/bensutherland/amplitools/)           

To obtain files, use the download button.       

Maintenance of amplitargets is driven by funding supporting amplitools [more info](https://github.com/bensutherland/amplitools/blob/main/20_docs/funding_support.md).     

The latest hotspot and region files are available within each species subfolder `current`.    
The reference genome connected to the current hotspot and regions files is given below. For details on previous hotspot and regions files (including associated reference genome), see species-specific log file.       


## Pacific oyster (_Crassostrea gigas_)  ##
See subfolder `cgig`.    

Reference genome: [GCA_000297895.1](https://www.ncbi.nlm.nih.gov/assembly/GCF_000297895.1/?shouldredirect=false)      

**Panel citation:** Sutherland et al. 2024. An amplicon panel for high-throughput and low-cost genotyping of Pacific oyster. _G3: Genes|Genomes|Genetics_, 14(9), jkae125. doi:https://doi.org/10.1093/g3journal/jkae125     

**Genome citation:** Zhang et al., 2012. The oyster genome reveals stress adaptation and complexity of shell formation. _Nature_. 490(7418), pp. 49-54.
